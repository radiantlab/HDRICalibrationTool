# Lens Mask Editor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user configure the lens mask at full window size, with a thin edge that can be compared against the fisheye circle, instead of on a small side-panel preview.

**Architecture:** The shadcn `Dialog` component (Radix under the hood, matching every other primitive in `src/components/ui`) hosts a second `ScaledCircularMaskSelection` driven by the *same* `MotionValue`s as the inline preview, so the two stay in sync with no extra state and no draft to apply or discard. `CircularMaskSelection` gains one presentational prop for the thin-edge mode.

**Tech Stack:** Next.js 15, React 19, shadcn/ui (new-york, radix base, lucide icons), Tailwind v4, framer-motion, Jest + Testing Library.

**Source spec:** `docs/superpowers/specs/2026-07-27-run-console-history-and-mask-editor.md`, section A.

## Scope note

This is one of three plans from that spec. The others are the run console (section B) and run history plus presets (section C). **Task 1 adds the `Dialog` primitive that the run console also needs**, so this plan should land first, or Task 1 should be lifted out and done once.

Spec parts A4 (zoom/pan) and A5 (fit-to-circle) are deliberately **out of scope**. Build A1 and A3 first, then decide whether the rest is still wanted. A5 in particular carries real risk: measuring the circle in `IMG_6962.JPG` gave about 20 px of uncertainty because the fisheye edge is soft.

## Global Constraints

- **Use shadcn/ui components, not hand-rolled equivalents.** The project is a configured shadcn project (`components.json`: new-york style, radix base, lucide icons, `@/components/ui` alias). Accessibility behaviour (focus trap, `aria-modal`, labelling, escape handling, scroll lock) comes from Radix and must not be reimplemented.
- **`npx shadcn` needs the sandbox disabled.** It fails with `EPERM` writing `~/.npm/_cacache`, which npm misreports as root-owned cache files; there are none. Run the add command with sandboxing off. The user can adjust this with `/sandbox`.
- **`jest.mock` must use the global `jest`, not the binding from `@jest/globals`.** The SWC transform only hoists the global form above imports. Importing it means the module under test loads before the mock registers and the real implementation runs. This cost an hour previously; do not repeat it.
- **The `@/` alias resolves in tests** via the `moduleNameMapper` in `jest.config.js`.
- **Radix components sometimes need jsdom shims.** `ResizeObserver` is already stubbed in `jest.setup.js`. If a Radix primitive trips over `hasPointerCapture`, `scrollIntoView` or `matchMedia`, add the stub there rather than reaching for `act` workarounds.
- **Numeric mask entry already exists** (`lens-mask-input.tsx:95-151`: Radius, X and Y inputs registered to `lensMask.*`, writing back to the motion values). Do not rebuild it; the dialog reuses the same values.
- **Test command:** `npm test`. Lint: `npm run check` (or `npx ultracite fix <files>`). Types: `npx tsc --noEmit`.
- **Prose in comments and UI copy uses no em dashes.**

### Task 2: Thin-edge mode on the mask circle

**Files:**
- Modify: `src/components/ui/circular-mask-selection.tsx:82` (the mask div className)
- Create: `__tests__/circular-mask-edge.test.tsx`

**Interfaces:**
- Consumes: nothing from Task 1.
- Produces: an optional `thinEdge?: boolean` prop on `CircularMaskSelection`, forwarded by `ScaledCircularMaskSelection` through its existing prop spread.

The mask is drawn with `border-3 border-red-500`. At preview scale one screen pixel is about six image pixels, so a 3 px border covers roughly eighteen image pixels of the very edge the user is trying to align against. A 1 px ring makes the comparison possible.

- [ ] **Step 1: Write the failing test**

Create `__tests__/circular-mask-edge.test.tsx`:

```tsx
import { describe, expect, it } from "@jest/globals";
import { render } from "@testing-library/react";
import { motionValue } from "framer-motion";
import { CircularMaskSelection } from "../src/components/ui/circular-mask-selection";

function renderMask(thinEdge: boolean) {
  const { container } = render(
    <CircularMaskSelection
      centerX={motionValue(100)}
      centerY={motionValue(100)}
      radiusAjusterCenterX={motionValue(150)}
      radiusAjusterCenterY={motionValue(100)}
      thinEdge={thinEdge}
    >
      <div />
    </CircularMaskSelection>
  );
  const circle = container.querySelector(".rounded-full");
  if (!circle) {
    throw new Error("expected the mask circle to render");
  }
  return circle;
}

describe("CircularMaskSelection edge", () => {
  it("draws a thick border by default", () => {
    expect(renderMask(false).className).toContain("border-3");
  });

  it("draws a single pixel ring in edge-check mode", () => {
    const className = renderMask(true).className;

    expect(className).toContain("border");
    expect(className).not.toContain("border-3");
  });
});
```

- [ ] **Step 3: Write the implementation**

Create `src/app/home-page/lens-mask-editor.tsx`:

```tsx
"use client";

import type { MotionValue } from "framer-motion";
import { Suspense, useId, useState } from "react";
import { GenericImage } from "@/components/ui/(image)/generic-image";
import { Checkbox } from "@/components/ui/checkbox";
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogHeader,
  DialogTitle,
} from "@/components/ui/dialog";
import { Label } from "@/components/ui/label";
import { Spinner } from "@/components/ui/spinner";
import { ScaledCircularMaskSelection } from "./fs-circular-mas-selection";

/**
 * The lens mask at full window size.
 *
 * It drives the same MotionValue instances as the inline preview, so there is
 * no draft state to apply or discard: closing the dialog just stops showing the
 * larger view. The numeric Radius/X/Y inputs already live in LensMaskInput and
 * are not duplicated here.
 */
export function LensMaskEditor({
  centerX,
  centerY,
  imagePath,
  onOpenChange,
  open,
  radiusAjusterCenterX,
  radiusAjusterCenterY,
}: {
  centerX: MotionValue<number>;
  centerY: MotionValue<number>;
  imagePath: string;
  onOpenChange: (open: boolean) => void;
  open: boolean;
  radiusAjusterCenterX: MotionValue<number>;
  radiusAjusterCenterY: MotionValue<number>;
}) {
  const [thinEdge, setThinEdge] = useState(false);
  const edgeCheckId = useId();

  return (
    <Dialog onOpenChange={onOpenChange} open={open}>
      <DialogContent className="flex h-[90vh] w-[90vw] max-w-none flex-col">
        <DialogHeader>
          <DialogTitle>Configure lens mask</DialogTitle>
          <DialogDescription>
            Drag the circle to move it and the handle to resize it. The Radius,
            X and Y fields in the sidebar stay in step and accept exact values.
          </DialogDescription>
        </DialogHeader>

        <div className="flex min-h-0 flex-1 items-center justify-center">
          <Suspense fallback={<Spinner />}>
            <ScaledCircularMaskSelection
              centerX={centerX}
              centerY={centerY}
              className="max-h-full max-w-full"
              imagePath={imagePath}
              radiusAjusterCenterX={radiusAjusterCenterX}
              radiusAjusterCenterY={radiusAjusterCenterY}
              thinEdge={thinEdge}
            >
              <GenericImage fsSrc={imagePath} />
            </ScaledCircularMaskSelection>
          </Suspense>
        </div>

        <div className="flex items-center gap-2">
          <Checkbox
            checked={thinEdge}
            id={edgeCheckId}
            onCheckedChange={(checked) => setThinEdge(Boolean(checked))}
          />
          <Label htmlFor={edgeCheckId}>
            Edge check: draw the mask as a single pixel ring
          </Label>
        </div>
      </DialogContent>
    </Dialog>
  );
}
```

`DialogContent` supplies its own close button, so no explicit Done button is
needed; escape and the backdrop also close it, all from Radix.

## Deliberately not built

- **Zoom and pan** (spec A4). Reassess after using the full-size editor; it may be enough.
- **Fit to circle** (spec A5). Auto-detection of the fisheye circle. Risky, since the soft edge gives roughly 20 px of uncertainty, and it must be offered as an estimate the user refines rather than an automatic action.
- **Numeric fields.** Already exist in `lens-mask-input.tsx`; the spec's claim that they were missing was wrong and has been corrected.
